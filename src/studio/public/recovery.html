      How to fix it · three ways

      A

      Sign in once and resume

      Recommended
      1. Run this in the chat (or pushreel login in a terminal). A browser window opens on your app; sign in the way you always do. It works with Google, GitHub and other OAuth logins, magic links and SSO. /pushreel login
      2. Close the window. The session is saved in .pushreel/auth.json (session cookies: do not commit it).
      3. Press Resume, or run /pushreel resume in the chat.
      4. Or, for an app with a password form: a test user without 2FA in your shell or in .env.local, then start the Studio again from that shell. export PUSHREEL_LOGIN="email:password"

      Neither the saved session nor the account is written into the shot list, the log or the videos.

      Export the public scenes only

      C

      My login needs 2FA or a captcha

      A limit

      Pushreel cannot pass those. Use a test environment where they are switched off for the test user. If that is not possible for your app: This is a limit of Pushreel. Write to hello@pushreel.dev and tell us about your app.

      Cancel this run

      End the paused run. Pushreel stops the app if it started it. The recorded scenes and shotlist.json are kept, so you can start again later without exploring twice.
